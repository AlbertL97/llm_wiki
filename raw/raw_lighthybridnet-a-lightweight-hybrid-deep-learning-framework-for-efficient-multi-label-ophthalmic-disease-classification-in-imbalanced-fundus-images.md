# LightHybridNet: A Lightweight Hybrid Deep Learning Framework for Efficient Multi-Label Ophthalmic Disease Classification in Imbalanced Fundus Images

**Authors:** Not specified in the provided text.

**Date:** 2026-10-18 (based on URL structure and last updated date requirement)

## Summary

Eye diseases pose a significant threat to global vision, necessitating accurate and early diagnosis. This study presents LightHybridNet, a novel lightweight hybrid deep learning framework designed to improve the classification of ophthalmic diseases from fundus images. The framework addresses challenges such as the complexity of visual features and imbalanced datasets by incorporating architectural innovations like depthwise separable convolutions and compound scaling. Pre-processing techniques (histogram equalization, color space conversion, contrast adjustment) and data augmentation were employed to enhance image quality and model generalization. The hybrid architecture allows the model to focus on pertinent image regions and integrate information at various scales. Evaluation on the ODIR-5K dataset showed that LightHybridNet outperformed baseline transfer-learning models, achieving a weighted F1-score of 91.51%, a macro AUC of 98.26%, and a Cohen's Kappa of 90.14%. Furthermore, the use of explainable AI methods like Grad-CAM improved model interpretability by highlighting influential features. LightHybridNet is presented as a significant advancement for reliable automated ocular disease detection in clinical settings.

## Key Findings

*   **Problem:** Accurate and early diagnosis of eye diseases from fundus images is crucial but challenging due to subtle visual features and imbalanced datasets.
*   **Solution:** Development of LightHybridNet, a lightweight hybrid deep learning framework.
*   **Methodology:**
    *   Incorporates depthwise separable convolutions and compound scaling.
    *   Utilizes pre-processing (histogram equalization, color space conversion, contrast adjustment).
    *   Employs image augmentation for improved generalization.
*   **Performance:** Outperforms baseline models on the ODIR-5K dataset with a weighted F1-score of 91.51%, macro AUC of 98.26%, and Cohen's Kappa of 90.14%.
*   **Interpretability:** Enhances model interpretability using explainable AI (Grad-CAM).
*   **Impact:** Represents a promising advancement for automated ocular disease detection and clinical reliability.
