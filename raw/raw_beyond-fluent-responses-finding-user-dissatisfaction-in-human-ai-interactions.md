# Beyond Fluent Responses: Finding User Dissatisfaction in Human-AI Interactions

**Authors:** Unspecified (based on provided link format)
**Date:** 2023-11-28 (estimated from arXiv version date)

## Summary

As AI models, particularly large language models (LLMs), become more adept at generating fluent and coherent responses, evaluating their performance requires a shift from solely response-centered metrics to user-centered ones. This paper investigates whether user dissatisfaction, a key aspect of user experience that may not directly correlate with response quality, can be detected from conversational text. The authors analyze user utterances labeled with self-reported dissatisfaction to identify predictive cues. Their findings indicate that user utterances contain signals of implicit dissatisfaction and that these signals can be effectively detected by machine learning models. The study also suggests that analyzing changes in user utterances from the preceding turn, particularly using anomaly detection methods, can enhance the accuracy of dissatisfaction detection. This work is crucial for developing AI systems that genuinely meet user needs and improve overall user satisfaction in real-world interactions.
