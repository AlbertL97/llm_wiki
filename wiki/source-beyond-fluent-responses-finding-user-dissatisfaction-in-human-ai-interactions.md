# Source Summary: Beyond Fluent Responses: Finding User Dissatisfaction in Human-AI Interactions

## Abstract

As large language models (LLMs) produce increasingly sophisticated responses, the focus of evaluation is shifting from traditional metrics like correctness and coherence to user-centered criteria such as preferences and perceived usefulness. This shift is vital for creating truly valuable AI technologies. This study explores whether user-centered signals of dissatisfaction can be identified from conversational text. Specifically, it examines user utterances marked with self-reported dissatisfaction to determine if this sentiment can be detected. The results show that models analyzing user utterances can detect dissatisfaction with significant accuracy, outperforming baseline methods.

## Key Findings

*   **Shift in Evaluation Criteria:** The field is moving from response-quality metrics (correctness, coherence) to user-centered metrics (preferences, usefulness) for LLM evaluation.
*   **Detecting Implicit Dissatisfaction:** User utterances in conversations contain signals that can implicitly indicate dissatisfaction, even when responses appear fluent.
*   **Text-Based Detection:** Dissatisfaction can be detected from conversational text using machine learning models trained on user-labeled dissatisfaction.
*   **Improved Detection Methods:** Analyzing changes from preceding user utterances and employing anomaly detection techniques can enhance the accuracy of dissatisfaction detection.
