# Source Summary: Delegating or Doing? Understanding User Behavior in Hybrid Human-Agent Interfaces

## Overview

This paper investigates how users interact with hybrid interfaces that combine traditional direct manipulation with Large Language Model (LLM) based conversational agents for task completion. The research examines the trade-offs users make between performing tasks themselves and delegating them to an AI assistant within a content management system. The study highlights that while AI delegation significantly reduces the *effort* involved in interaction (measured by clicks, navigation, and scrolling), it does not necessarily lead to faster task completion times. A key finding is that the decision to delegate is predominantly driven by individual user characteristics rather than the nature or perceived risk of the task itself.

## Key Findings

*   **Interaction Effort Reduction:** The integration of LLM agents demonstrably lowers the interaction effort required for users to complete tasks.
*   **Task Duration Unaffected:** Contrary to expectations, the use of AI assistance did not result in a statistically significant decrease in overall task completion time.
*   **Individual Differences Drive Delegation:** The choice to delegate tasks to the AI is highly personalized, with individual user differences explaining a substantial portion of the variance in assistant usage.
*   **Task Characteristics Do Not Predict Delegation:** Users do not appear to strategically delegate based on task type or perceived risk.
*   **Focus on Effort Savings:** The primary benefit of current human-agent interfaces may be in streamlining the user experience through reduced interaction burden rather than pure speed enhancement.

## Methodology

*   **Study Type:** Between-subjects experiment.
*   **Participants:** 73 individuals.
*   **System:** A content management system enhanced with an LLM agent via the Model Context Protocol (MCP).
*   **Conditions:** Three interaction modes were compared: Traditional-Only, AI-First, and Hybrid.
*   **Tasks:** Sixteen scenarios involving CRUD operations.
*   **Metrics:** Task completion time, interaction logs, and observed delegation behaviors.
