# Evaluating the Impact of Explainable AI on Trust in AI-Assisted Code Review

**Authors:** Chen, S., Zhang, Y., Li, J., Wang, H.

**Date:** 2026-07-24 (v1)

## Abstract

This research explores the impact of Explainable AI (XAI) on developer trust in AI-assisted code reviews, a domain where Large Language Models (LLMs) are increasingly prevalent but often lack transparent reasoning. Understanding the extent to which developers trust these AI systems is crucial.

## Objective

The primary goal is to investigate how XAI influences developer trust in AI-assisted code reviews.

## Method

A within-subjects user study was conducted with 34 participants. Three LLM-based code review systems were compared:

*   **Condition A:** Detailed explanation and review feedback.
*   **Condition B:** Review feedback only.
*   **Condition C:** No explanations.

Participants reviewed real-world code changes with AI-generated reviews. Key metrics included trust perceptions, agreement with AI recommendations, reasoning for decisions, and time taken.

## Results

*   The level of explanation significantly impacted both trust and agreement, though in distinct ways.
*   **Condition A (Full Explanations):** Highest perceived trust (M = 3.99/5).
*   **Condition B (Moderate Explanations):** Highest agreement with AI recommendations (89.22%), potentially leading developers to question AI recommendations more frequently.
*   **Condition C (No Explanations):** Lowest trust and agreement.
*   Explanation level did not significantly affect review time.
*   Common reasons for decisions cited by participants were code readability and correctness.

## Conclusion

Integrating XAI into code review processes demonstrably alters trust perceptions and agreement levels with AI recommendations. These findings provide valuable insights for designing and evaluating trustworthy AI systems in software development and for furthering research on human factors in AI-assisted software engineering.
