# How Anthropomorphic Attitudes Toward Agents Divide User Behavior, and How Design Should Change

**Last updated:** 2026-10-12

## Introduction
This paper explores the impact of anthropomorphic attitudes, specifically user-driven renaming of conversational agents, on user behavior and preferences. It addresses a gap in field evidence regarding how such attitudinal shifts affect interaction patterns and whether agent design should adapt.

## Methodology
A field study was conducted with a desktop assistant between May and August 2026, involving 257 users. User behavior was analyzed using a sparse-autoencoder codebook, identity tags, and opening lexicons. The study also involved user judgments on revised agent responses.

## Key Findings

*   **Anthropomorphism and Behavior Division:** Renaming the assistant, an act of anthropomorphism, was found to significantly divide user behavior patterns.
*   **User Interaction Styles:** Users who renamed the agent exhibited different interaction styles, greeting more and commanding less, compared to those who used the default name.
*   **Task Orientation:** Renaming was associated with an introverted, task-only orientation, contrasting with the default name users.
*   **Agent Design Preferences:** A revised agent design that prioritizes relational openings (greetings, affect reception) and direct task execution was preferred by users who renamed the agent. These users favored the revised replies for being treated as a person and having affect received.
*   **Confiding Gap:** The agent's codebook revealed a significant gap in its ability to handle 'confiding' interactions.

## Conclusion
The study highlights the importance of considering user anthropomorphic attitudes in agent design. Tailoring agent responses to acknowledge user preferences for social connection and personal treatment can enhance user satisfaction, even when the primary function is task-oriented.
