# Source Summary: Humanlikeness as Design, Anthropomorphism as Inference: A Conceptual Framework for Human–Robot Interaction

## Main Findings

This article proposes a key distinction between 'humanlikeness' as a deliberate design choice for robots and 'anthropomorphism' as the human tendency to infer human-like characteristics onto those robots. The authors present a conceptual framework that separates the design intent from the user's cognitive process, arguing that this differentiation is crucial for understanding and improving human-robot interaction.

## Key Concepts

*   **Humanlikeness:** Defined as an intentional aspect of robot design, where features are incorporated to make the robot appear similar to humans.
*   **Anthropomorphism:** Defined as the inferential process by which humans attribute human qualities, intentions, and emotions to non-human entities, such as robots.
*   **Conceptual Framework:** A model that distinguishes between the designer's goal of making robots human-like and the user's interpretation of those robots as possessing human traits.
*   **Implications for HRI:** Understanding this distinction is essential for designing robots that effectively manage user trust, engagement, and overall interaction experience. It allows for more precise strategies in robot design and user studies.
